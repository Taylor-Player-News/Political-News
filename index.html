What happened

The Political News App automation has built this app several times. Each run built it inside its own temporary machine and finished without pushing anywhere, so nothing survived the run. This repository was created but stayed empty, which is why there was never a link to open.

To get the real app here

  1. Add a Cursor secret named GITHUB_TOKEN (a GitHub token with Contents and Pages write access) in Cloud Agent settings. A token pasted into chat will not work — runs are expected to refuse it, and it only lasts for that one conversation.
  2. Add a publishing step to the Political News App automation prompt: build the app, then commit and push the built output to Taylor-Player-News/Political-News on main, which is already serving this page.
  3. Run the automation. It will overwrite this page with the app.
Pages is already enabled on this repository, so a push to main goes live in under a minute.
